日本語

このポートフォリオは、奥山貴希の制作物と技術情報を紹介する静的Webサイトです。

このサイトが保存する情報

  • 表示言語の選択（日本語または英語）だけを、閲覧者のブラウザ内のlocalStorageへ保存します。
  • この情報はサーバーへ送信せず、氏名、メールアドレス、日記本文、認証情報は収集しません。
  • 保存は、閲覧者がブラウザのサイトデータを削除するまで続きます。

外部サービス

  • 作品紹介動画は権利確認が終わるまで無効です。現在のページはYouTubeへ接続せず、動画IDも有効化していません。
  • GitHub、Render、unityroomへのリンクを開いた後は、各サービスのプライバシー条件が適用されます。YouTubeを将来再有効化する場合も同様です。
  • サイトの配信基盤であるGitHub Pagesは、サービス運用上のアクセス情報を処理する場合があります。

広告・解析・問い合わせ

このサイト独自の広告、アクセス解析、問い合わせフォームはありません。問い合わせはGitHubプロフィールに掲載された連絡手段を利用し、公開Issueへ個人情報を書き込まないでください。

English

This is a static website presenting Takaki Okuyama's projects and technical work.

Information stored by this site

  • Only the selected display language (Japanese or English) is stored in the visitor's browser using localStorage.
  • This value is not sent to this site's server. The site does not collect names, email addresses, diary content, or authentication data.
  • The preference remains until the visitor deletes the site's browser data.

External services

  • The introduction video is disabled until its rights review is complete. The current page does not connect to YouTube or activate a video identifier.
  • After opening GitHub, Render, or unityroom links, each service's own privacy terms apply. The same will apply if YouTube is re-enabled in the future.
  • GitHub Pages, the hosting platform, may process access information needed to operate the service.

Advertising, analytics, and contact

This site has no first-party advertising, analytics, or contact form. Use a contact method listed on the GitHub profile and do not post personal information in a public Issue.
