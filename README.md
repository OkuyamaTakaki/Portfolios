# 2025-Portfolio

2025年 10月13日 月曜日 時点 webサイトを公開するときは以下に注意してください。

１，ディレクトリやファイルの配置について
mainの直下に必ずindex.html というファイルを配置してください。
index.html はwebサイトのトップページを意味します。
index.html がないとwebサイトが表示されません。
ファイル名も必ず index.html としてください。

２，フォルダ名について
リポジトリ名の Portfolios を フォルダ名に使用しないでください。
リポジトリ名とファイル名が同じ名前のときに、
意図したwebサイトが表示されない可能性があります。
